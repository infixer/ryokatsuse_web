# ryokatsu.dev

## 自然文で記事・登壇資料を探す（Jev）

トップページの「どんな話が読みたい？」から、ブログ記事と `src/lib/talks.ts`
の登壇資料を横断して探せます。既存のヘッダーのキーワード検索も利用できます。

- `POST /api/discover` に `{ "query": "アクセシビリティの自動テストの仕組みを知りたい" }` を送信。
- Workers AI の `typesafe/jev` にタイトルと説明（記事は説明文または本文冒頭の抜粋、資料はイベント名と日付）を渡し、0〜3の関連度を評価。
- 関連度2以上から上位5件を表示。結果がなければ再入力を案内します。スコアは正解確率として表示しません。
- 記事本文全体や外部の登壇資料本文は検索対象に含みません。日本語の言い換え・専門用語の精度は実データで確認してください。
- 全候補を最大32件かつ24,000 UTF-8バイト以内に分割し、同時2呼び出しまでで評価します。1検索が複数の有料モデル呼び出しになります。データが増えると呼び出し数も増えるため、将来は候補検索・reranking方式を検討してください。
- クライアントは送信時だけAPIを呼びます。200文字・リクエスト本文2KB・同一Originの制限と、CloudflareのIP単位5回/分のレート制限を設けています。レート制限はCloudflare拠点単位の近似制限であり、アカウント全体の厳密な予算上限ではありません。
- サーバーのモデル待機は15秒、ブラウザは20秒で打ち切ります。受付済みのモデル推論自体がキャンセルされる保証はありません。検索文やモデル応答をアプリのログへ出力せず、レスポンスは `no-store` にします。
- URL・タイトルは登録済みのコンテンツから取得し、モデルには生成させません。

### Cloudflare設定とローカル確認

`wrangler.jsonc` に `AI` と `DISCOVERY_RATE_LIMITER` のバインディングを定義しています。
レート制限の `namespace_id: "1001"` はこの機能用です。同一アカウントの別Workerで使用済みなら、未使用の番号に変更してください。
Jevは第三者モデルです。デプロイ前にCloudflareのダッシュボードで利用可否・必要な利用設定・料金を確認してください。

```sh
pnpm install --frozen-lockfile
pnpm test:discovery
pnpm astro check
pnpm build
pnpm dev
```

実モデルをローカルで試す場合は `pnpm wrangler login` で認証し、`JEV_REMOTE=true pnpm dev` を実行してください。既定ではAstroの `remoteBindings` を無効にして認証なしでビルド・画面開発できるようにしています。本番のAIバインディングを無効にする設定ではありません。ローカル開発でも実モデルの呼び出しには料金が発生します。リモート接続・認証・モデル利用設定がない場合は検索エラーを表示します。

自動テストはAIバインディングを差し替え、バッチの入力上限、全候補の網羅、並び順・件数、登録URLのみの返却、不正入力、回数制限、モデル異常を検証します。実際の日本語検索精度は別途、以下のような入力で確認してください。

- 「アクセシビリティの自動テストが内部で何をしているか知りたい」→ axe-coreの記事・登壇資料
- 「ブラウザの仕様の読み方について知りたい」→ Web IDLなど
- ブログで扱っていないテーマ → 無関係な候補を出さないこと
