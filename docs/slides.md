# ブログ記事からスライドを生成する

登壇資料を「スライドを先に作る」のではなく、**ブログ記事（= 公開されたスピーカーノート）を先に書き、そこからスライドを生成する**ための仕組みです。

## 使い方

記事の frontmatter に `slides` を足すと、`/slides/<記事id>` にスライドが静的生成され、記事ページに「スライドで見る」リンクが出ます。

```yaml
---
title: Web IDLって知ってる？
publishDate: "2026-06-06"
slides:
  theme: keynote        # プリセット（下記）。省略時 keynote
  event: フロントエンド・PHPカンファレンス北海道2026 LT
  # title / subtitle / date も上書きできる（省略時は記事の title / description / publishDate）
  # steps: true         # リスト項目を 1 つずつ出す
---
```

すべて既定値でよければ `slides: true` だけでも動きます。

## 本文 → スライドの変換ルール

| 本文 | スライド |
| --- | --- |
| 最初の `##` より前の段落 | 表紙のスピーカーノート |
| `##` | 章。直後に `###` が続くと「章扉」スライドになる |
| `###` 以下 | 1 枚のスライド。上に章タイトルが小さく出る |
| `---` | 同じ見出しのままスライドを分ける |
| 段落 | **スピーカーノート**（スライドには出ない） |
| リスト・コード・画像・引用・表・`<LinkCard />` | スライドに出る |
| YouTube・Speaker Deck などの `<iframe>` | 動画・埋め込みスライド（元の比率を保って最大化） |
| X のポスト（`blockquote.twitter-tweet`） | 引用カード（widgets.js は読まずに静的に出す） |
| そのほかの生 HTML（`<div>` など） | そのまま出す（`<script>` とコメントは除く） |
| 見出しの下に段落しかない | 段落中の `**太字**`（最大 3 つ）をキーメッセージとして大きく出す |

- 基本的に「記事に載っているものはスライドにも出す」方針です。段落だけがノートに回ります。
- コード・画像・表・埋め込み・X のポストは 1 枚に 1 つまで。2 つ目は自動で次のスライドに送り、その直前の段落も一緒にそのスライドのノートになります。
- 埋め込みは表示中のスライドだけ読み込み、スライドを離れると外すので、動画が裏で再生され続けません。
- 見出しのない記事は、導入の段落を表紙ではなく最初の表示物（動画など）のスライドのノートにします。
- レイアウト（箇条書き・コード・画像・引用・表・ステートメントなど）は中身から自動で選びます。
- MDX の `import`、`<Cite />`、`<LinkCard />` 以外の大文字のコンポーネントはスライドでは扱いません。

つまり「スライドに出したいもの＝リスト・コード・画像・太字」「話す内容＝段落」と意識して記事を書くと、そのままスライドになります。

## プリセット（テンプレート）

見た目とアニメーションのセットです。`src/styles/slides.css` の `[data-theme='…']` で定義しています。

| 名前 | 雰囲気 | スライド遷移 | 要素の出方 |
| --- | --- | --- | --- |
| `keynote` | 暗い背景・グラデーション文字 | ふわっと拡大縮小 | ぼかしから浮き上がる |
| `paper` | 紙っぽい明るい背景・明朝見出し | 横にスライド | 左から拭うように出る・下線が伸びる |
| `terminal` | 黒地に緑・等幅 | カット（ちらつき） | 見出しが打鍵され、要素が点滅して出る |
| `pop` | 明るい色・太枠と影 | 下から弾んで入る | ポンと弾んで出る |

各プリセットの実例：

| プリセット | 記事 |
| --- | --- |
| `keynote`（`steps: true`） | `2026/frontend-phpcon-do-lt-web-idl`（コード・表・画像） |
| `paper` | `2026/a11y-chiba-2026`（X のポスト・YouTube） |
| `terminal` | `2026/burikaigi-2026`（Speaker Deck・画像） |
| `pop` | `2026/like-weapon`（見出しなし・YouTube） |

`?theme=paper` を URL に付けるか、スライド上で `T` キーを押すと、記事の設定を変えずに他のプリセットを試せます。

新しいプリセットを足すときは、`packages/core/src/schema.ts` の `slideThemes` に名前を追加し、`slides.css` に `[data-theme='名前']` で変数（`--bg` `--fg` `--accent` …）と `--enter`（要素の登場アニメーション）・`--slide-from` / `--slide-to`（遷移）を定義します。

## 表紙の自己紹介

表紙の右下に、丸く切り抜いたアイコン・名前（infixer）・X / Bluesky / GitHub / infixer.net へのリンクを出します。内容は `src/lib/slides/profile.ts`、アイコンは `public/images/infixer-icon.jpg` で変えられます。

## 操作

| キー | 動作 |
| --- | --- |
| → ↓ Space Enter PageDown / クリック / 左スワイプ | 次へ |
| ← ↑ Backspace PageUp / 画面左 1/3 をクリック / 右スワイプ | 前へ |
| Home / End | 最初 / 最後 |
| N | スピーカーノートを重ねて表示 |
| P | 発表者ビューを別ウィンドウで開く（現在・次のスライド、ノート、タイマー。本体と同期） |
| F | 全画面 |
| T | プリセットを切り替えて試す |

- URL の `#3` で 3 枚目から開けます。
- ブラウザの印刷（PDF 保存）で 1 枚 1 ページの PDF になります。
- `prefers-reduced-motion` が有効な環境ではアニメーションを止めます。

## 実装

| ファイル | 役割 |
| --- | --- |
| `src/lib/slides/build.ts` | Markdown/MDX 本文 → スライド構造の変換（Shiki でコードをハイライト） |
| `src/pages/slides/[...slug].astro` | `slides` を持つ記事のスライドページをビルド時に生成 |
| `src/lib/slides/profile.ts` | 表紙に出す自己紹介（名前・アイコン・リンク） |
| `src/lib/slides/runtime.ts` | 操作・発表者ビュー・同期（BroadcastChannel） |
| `src/styles/slides.css` | 共通レイアウトとプリセット |
| `tests/slides.test.ts` | 変換ルールのテスト（`pnpm test:slides`） |
